# MyCS2Module

Модуль DLL для CS2 на C++17 с автоматическим отслеживанием и горячей перезагрузкой оффсетов.

## Архитектура и особенности

1. **Динамический мониторинг смещений (`OffsetWatcher`)**:
   - Читает смещения прямо из локальной папки `cs222/output` (`offsets.json` и `client_dll.json`).
   - Использует `FindFirstChangeNotificationW` (Windows API): мгновенно и без нагрузки на CPU обновляет переменные памяти при изменении или обновлении дампа.
2. **Легковесный парсер**:
   - Извлекает только необходимые указатели (`dwEntityList`, `dwViewMatrix`, `dwLocalPlayerController`, `m_iHealth`, `m_vecAbsOrigin`, `m_bPawnIsAlive` и т.д.), не тратя память на гигабайты ненужных структур.
3. **Рендерер**:
   - Базовый оверлей (боксы, полоски здоровья, информация о бомбе, переключение по клавише `F11`, выгрузка по `END`).

## Сборка

Запустите `build.bat` в папке проекта (автоматически найдет установленную Visual Studio и скомпилирует `MyCS2Module.dll` под x64).
